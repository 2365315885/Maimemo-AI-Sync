# 📖 Maimemo-Gemini-Sync (墨墨背单词 & Gemini 同步助手)

基于 Streamlit 框架构建的自动化效率工具。通过对接 Gemini AI 与墨墨背单词 OpenAPI，实现英文阅读真题的智能精翻、生词提取，并**一键将专属释义与扩展助记精准推送到个人的墨墨云词本中**。

## 🚀 核心特性

- **🤖 完美对接 LLM**：将庞大、无序的英文阅读真题文本转化为结构化的高质生词 JSON 数据。
- **🎯 O(1) 精准追加**：摒弃低效的遍历查询，基于唯一 ID 直达专属云词本，实现无损去重追加。
- **🛡️ 极致抗封锁与容错**：
  - **防 WAF 拦截**：采用全局 HTTP Session 复用底层 TCP 连接，配合智能休眠算法，完美遵守墨墨官方 `60秒40次` 的严苛请求频控。
  - **隐形包装透传**：通过自研的 `extract_safe` 补丁，完美解析官方文档遗漏的 `{"data": {...}}` 隐形数据包装层。
  - **防 500 崩溃机制**：修正了官方文档在助记枚举类型上的“句号坑”，并隐式注入必需的 `status` 字段，彻底根除因数据库完整性约束导致的服务端异常崩溃。

## 🛠️ 安装与本地运行

项目环境要求：Python 3.8+

```bash
# 1. 克隆项目到本地
git clone [https://github.com/YourUsername/Maimemo-Gemini-Sync.git](https://github.com/YourUsername/Maimemo-Gemini-Sync.git)
cd Maimemo-Gemini-Sync

# 2. 安装依赖
pip install -r requirements.txt

# 3. 运行 Web 界面
streamlit run app.py

💡 使用工作流
配置 Token：在墨墨 App 中前往 我的 -> 更多设置 -> 实验功能 -> API 开放 获取个人专属 Token。

初始化词本：首次使用，点击网页端的【自动生成专属词本】，获取到一串唯一的词本 ID 并填入配置栏。

获取结构化数据：将英文长难段落配合下方的专属提示词发给 Gemini，获取纯 JSON 格式的返回。

一键入库：将 JSON 代码粘贴至网页端输入框，点击同步。工具将自动在后台进行排队、核对、去重及写入操作。

📌 Gemini 专属系统提示词 (Prompt)
你是一个精翻与词汇解析专家。当我发送一段英文段落给你时，请你完成以下两项任务：

任务 1：精翻与拆解
提供流畅、准确的中文精翻。对于长难句请进行极其简要的语法结构拆解。

任务 2：生词提取与自动化 JSON 输出
提取文本中的核心生词或长难词，为每个词提供精准释义，并构思能够加深印象的词根词缀拆解或联想助记。

⚠️ 格式要求：
在你完成精翻后，请务必在回答的最底部，输出一个纯正的 JSON 格式代码块，包含你提取的所有生词。不要在 JSON 内部包含多余标点、序号或说明文字，格式严格如下：

JSON
{
  "words": [
    {
      "spelling": "abandon",
      "interpretation": "vt. 放弃，抛弃；沉溺于",
      "note": "a(不)+band(绑定)+on -> 不再绑定 -> 放弃"
    }
  ]
}
